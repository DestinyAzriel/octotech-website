# OctoTech Ltd — Web Platform

Official website for **OctoTech Ltd**, a technology studio operating across Auckland, New Zealand and Lilongwe, Malawi.

Led by **Founder Telly Paul** (Auckland, NZ) and **Technical Lead Destiny Mwafulirwa** (Lilongwe, MW), OctoTech builds custom software platforms, mobile applications, database architectures, and secure network infrastructure.

---

## 🚀 Key Features & Pages

- **Live Bi-Continental Status Strip**: Real-time localized time tracking for CAT (UTC+2) and NZST/NZDT (UTC+12/13).
- **Home (`/`)**: Asymmetrical hero, interactive CLI network simulator, 4-step transparent engagement process, capabilities, problem solver, and shipped product highlights.
- **Services (`/services`)**: Technical deliverables and tech stack breakdowns (Web & Mobile, IT Infrastructure & VPN, Databases & APIs, System Maintenance).
- **Solutions (`/solutions`)**: Interactive problem-mapping matrix connecting client quotes directly to technical blueprints.
- **Products (`/products`)**: Deep dives into **OctoVVPN** (live at [octovvpn.net](https://octovvpn.net)) and **OctoPay** (cross-wallet money settlement layer).
- **About (`/about`)**: Studio history, leadership bios for Founder Telly Paul and Technical Lead Destiny Mwafulirwa, and phase-by-phase team expansion roadmap.
- **Contact (`/contact`)**: Fixed-price inquiry gateway with problem routing parameters, budget selectors, and direct verification links.

---

## 🛠️ Technology Stack

- **Framework**: Next.js 16 (App Router with Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 (`@theme` design tokens)
- **Icons**: Lucide React
- **Design System Tokens**: Ink (`#14213D`), Paper (`#FAFAF7`), Slate (`#4A5568`), Signal Amber (`#E2A537`), Hairline (`#E4E4DF`)
